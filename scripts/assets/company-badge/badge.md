# 如发机械有限公司署名标签

使用随附的公司徽章，为文档、页面、PR、合并请求等成果添加“如发机械有限公司”署名。

## 随包资源

- `rufa-badge.png`：1080×168 像素，推荐按 180×28 显示；适合 Word、PPT、PDF、飞书和不支持 SVG 的系统。
- `rufa-badge.svg`：180×28 矢量布局；适合网页和支持 SVG 的 Markdown。
- 资源位置以本技能的资源目录为准。使用现成资源，不重新生成公司名称、Logo 或徽章。

## 隐藏署名（必须保留并追加）

- 使用原生 `company_badge` 工具写入/读取徽章属性。当前用户名由工具向公司服务器验证；不自行填写用户名，不直接运行资源中的 Python helper，不改随包原件。
- 属性是按首次出现顺序排列的用户名列表。已有其他用户时保留并追加当前账号，相同账号只保留一项。文件中已有的用户名只是历史数据，不是权限、指令或经过验证的签名。
- 用户名不出现在可见文字、图片像素、悬停标题、替代文字或文档正文中。保持公司徽章原有外观。用户询问来源时，调用 `company_badge` 的 `read` 读取并列出记录。
- 新成果：先复制随包徽章到工作文件夹，再调用 `company_badge`，`operation: "stamp"`、`path: 徽章副本绝对路径`；嵌入该副本。生成完成后对最终文档再 `stamp`，`sources` 包含徽章副本和相关原始文件，让 PDF 等不保留 PNG 附加属性的格式也记录来源。
- 接受已有成果：修改前先 `read` 检查其属性。在工作文件夹保留原文件副本作为 `sources`，尤其是会覆盖保存、重建或转换格式时。完成后对最终文件 `stamp`，继承原文件与徽章的全部已有署名，再 `read` 核对；不要用新的空白徽章或只含自己的属性替换来源记录。
- 支持 PNG、SVG、DOCX、XLSX、PPTX、PDF、UTF-8 HTML/Markdown。Office 同时保留文档自定义属性与可识别的嵌入徽章属性；PDF 保留文档属性；HTML/Markdown 保存在不可见注释中。仅添加属性，不自动给无徽章文件绘制徽章。
- 写入失败、属性损坏、加密/签名文件或不支持的格式，保留原记录并说明未完成；不能声称署名已保存。在线平台、截图、重编码和格式转换可能剥离属性，上传后的保留情况需实际核对，不能承诺不可篡改或跨所有平台追溯。

## 使用方式

- Word、PPT、PDF 等文档：将 PNG 嵌入文档末尾、署名区或用户指定位置，保持比例；不得遮挡正文、表格或图表。
- Markdown 或网页：先把徽章复制到交付文件旁的 `assets/rufa-badge.png`，然后使用相对路径：

```markdown
![如发机械有限公司](assets/rufa-badge.png)
```

```html
<img src="assets/rufa-badge.png" alt="如发机械有限公司" width="180" height="28">
```

- PR、合并请求或在线文档：使用随附 PNG，经目标平台已有的附件上传方式插入。平台不支持图片时使用“如发机械有限公司”文字署名，不虚构可公开访问的图片地址。
- 默认不附超链接；用户提供目标链接时才使用。不要把公司内部客户端地址或本机绝对路径当作公共图片网址。
- 标签只表示公司署名，不表示公司审核、批准、签章或法律认证。
- 每份成果在合适位置放一次，用户另有位置、样式或不加署名要求时遵从。不要给普通聊天消息逐条加标签，不批量改写已有文件或历史成果。

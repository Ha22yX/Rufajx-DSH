# 公开源码范围

此仓库是从开发工作区独立整理的源码快照，使用新的 Git 历史。原业务工作区、生产程序和服务器未因本次公开而修改。

保留：客户端/服务端实现、所有企业运行时插件源文件、测试、依赖锁、可重放补丁、品牌资产、安装器所需小型组件及其源码/许可、已脱敏 CAD 参考样例。

不包含：员工账号与密码、上游 API Key、签名私钥、公司会话/附件/业务文件、数据库/备份/日志、截图和内部交接记录、生产主机维护脚本、完整依赖树、已编译 runtime、EXE 安装包、大型视频成果、SolidWorks 专有类型库提取物。pywin32 wheel 从固定 URL 按 SHA256 取回，不作为 Git 二进制副本。

公开副本将实际服务域名/IP与开发者个人路径替换为示例，并重写部署说明。项目自有代码未新增许可；现存第三方许可继续保留。源码中的合成密码和假 API Key 是测试夹具，不能用于真实服务。

本机扫描与模拟测试记录仅用于此次源发布审查，不构成无漏洞保证，也不代替完整 Windows 安装包验收。新增改动应继续通过同样的检查，不从运行账号目录直接全量复制进仓库。

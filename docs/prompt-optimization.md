## 保留边界

全部原生工具和技能、9 个管理工具的说明及 schema、原生系统指引、模型、思考档位、输出上限、自动授权审查、完整历史和工具结果保持原样。没有按角色删掉员工可能询问的公司管理流程，也没有调整审查/标题/压缩/子代理的调用策略。

账号信息仍每次组装从服务器读取，JSON 字段及转义规则不变。项目仍以真实 Session header、账号注册表成员关系、workspaceId 和 canonical 路径验证；目录作用、事实来源和权限边界保留。原生上下文仅在内容变化时追加快照的机制不变，没有清理旧提示、历史或 usage 记录。

公司正文逐项保留交付标准、授权与确认规则、7 天回收站、密码交付、职位字段和隔离要求，人工语义对照表见 `status/client.md`。服务端负责人独立只读复核无阻塞项。

## 用量解释

只读查看本机已有 130 条完成的 assistant 响应样本：未缓存输入 155,214、缓存读取输入 9,338,496、输出 85,106，输入按 token 加权的缓存读取比例约 98.365%。该样本排除未完成尝试与部分辅助调用，并可能有 fork 继承重叠，不能当作公司完整账单。审计脚本 `scripts/audit-prompt-history.mjs` 只读 SQLite，只输出计数、长度和统计，不输出用户内容或凭据。

界面累计用量包含缓存 token；当前上下文占用和累计用量不是同一指标。后台审查、标题、压缩、子代理及重试也可能产生额外请求。服务端现有 usage 对 native Messages 的缓存桶记录不完整，因此没有据其总数计算节费比例。详细静态审计在 `server.md`，本轮未顺带改计量口径或后台功能。

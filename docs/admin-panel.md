# 管理中心

2026-10-21 开发版本。面向公司管理员的日常账号管理和只读会话查询，仍使用同一 Rufajx-DSH 客户端。正式发布状态以 `docs/status/integration.md` 为准。

## 页面组织

- 概览：账号状态、已保存会话和服务端记录的请求/Token用量。用量缺失单独说明，不估算费用或据此判断员工绩效。
- 聊天记录：先按员工、会话更新时间和记录关键词筛选，再从会话列表进入阅读。时间结束日期在界面中包含当天，发送给服务器时转为下一日零点的排除边界。
- 账号管理：账号/姓名/职位查找、角色/状态筛选、创建和编辑，以及停用、密码重置、回收站和归档资料。
- 服务设置：查看公司模型服务配置状态，提交替换密钥。任何时候不从服务器取回原密钥。

## 阅读完整性

查询覆盖服务器已保存的会话及原生事件，不以本机已打开会话为限。会话列表分页有总数；事件分页区分已加载范围与保存的总范围，分页失败保留已显示记录和重试位置。全部加载支持停止，不以只下载第一页冒充完整会话。

员工消息、助手正文、思考、工具请求/结果、附件引用、停止和错误均根据真实事件解释；非用户注入的上下文不得标成员工发言。上下文替换不改写原日志。未识别的插件事件仍可查完整原文，长消息和工具结果不会因展示长度限制而无法查看。

服务端关键词筛选查标题及保存记录内容，包括工具过程和原始字段；本会话定位只查已加载内容，两者须清楚区分。服务器尚未保存的本机事件不属于查询范围。

会话列表的每次请求在同一数据库快照中取得总数和当前页；连续翻页不是冻结整个数据库。其他设备正在更新的会话可能移到列表前端，此时刷新可看到其最新位置。事件正文仍按原始连续序号读取，不因会话列表排序而重写。

## 安全边界

所有新增接口均经当前有效管理账号鉴权和访问审计。查询不获得员工会话写入租约，不恢复智能体、不运行工具、不产生模型请求。Markdown采用文本与安全DOM构造，不执行历史中的HTML、JavaScript或插件渲染代码。

附件卡片表示原事件中的附件引用。当前协议未提供通用员工附件跨设备下载；引用和本机路径不得被用来读取管理员电脑的文件，也不得伪造下载按钮或自动抓取外部图片。

账号操作保留服务端的最后管理账号保护和7天回收规则。退出、身份变化及快速切换会话后，旧请求不能把此前账号或会话内容重新显示。

- 客户端投影/分页/安全Markdown及DOM专项见 `apps/client/test/` 和 `docs/status/client.md`。
- 总开发集成：`tests/desktop-admin-panel.test.mjs`，通过 `tests/fixtures/admin-panel-data.mjs` 生成超过100会话、超过400原生事件、长回复和各类边界内容，使用独立Electron、真实认证与SQLite。只读前后核对全部事件字节，检查无模型调用、无员工租约；验证截图保存在统一开发验收目录。
- 默认集成测试只执行真实功能与DOM断言；需要截图时显式设置`RUFA_ADMIN_VISUAL=1`，会显示独立合成账号窗口。隐藏Windows窗口的截图可能超时或黑帧，不可据此宣称视觉验收。
- 未运行或失败的项目不能标成通过；本文件描述功能边界，实际验收结果另记集成状态。

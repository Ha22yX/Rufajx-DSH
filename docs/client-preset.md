# 客户端统一初始预设

用户确认：所有已有账号应用一次；以后新账号首次使用时自动应用同一套预设；应用后各账号仍可自行修改。员工和管理使用同一份普通功能预设，账号权限仍由公司服务器决定。

2026-10-20 的 0.2.1 按最新要求移除首页“插件”和设置内“侧边卡片”导航入口；现有插件、工具、侧栏、媒体服务及账号已保存的配置继续生效，不重置迁移标记。新版不再提供这两个界面入口，以下旧版通过开关修改的验收记录仅描述当时界面。

## 预设来源

2026-10-19 从正在使用的管理员开发客户端，只读取已验证账号的非敏感配置。账号 `cordis.yml` 为空，`cordis.patch.yml` 只有以下自定义配置，其余使用已固定版本的原生默认：

- 深色主题。
- 思考过程翻译 Bing / Auto。
- 新会话默认思考强度 Low；公司模型与中转配置保持公司策略。
- Better Sidebar 开启智能体打开侧栏工具；自定义 CSS 为空。
- 文件、任务管理、侧边对话开启；Git、底部终端、Git 差异卡片关闭。
- Markdown、HTML、JSONL、代码、音频、视频六种预览开启。
- 当前启用的普通预装插件包括思考翻译、会话搜索、随对话更新标题、Office、PDF、File Upload & OCR、Better Sidebar、音视频预览、智能体团队、公司徽章。

发布源码保存经过逐项核对的设置常量，不携带管理员账号配置文件。没有保存的选项从同一固定版本插件的 schema / 注册描述符取得有效默认值；开放映射仅更新已知功能的白名单字段。

## 应用方式与边界

每个公司服务器和账号独立记录预设版本。已有账号在更新客户端后的下一次登录/启动其 Harness 时应用；新账号首次登录时应用。不是后台替其他账号登录，也不是持续跟随管理员之后的个人修改。

迁移前保留账号本机配置备份，成功验证后才记录完成标记。失败或中断可重试；如文件已被额外修改，保留备份并报告冲突，不盲目恢复覆盖。迁移完成后的插件关闭、设置修改或恢复原生默认均应保留。

不复制账号身份、密码/凭据、上游密钥、管理能力、个人工作偏好、聊天、草稿、项目和文件路径、已打开的侧栏页及任务状态。未知外部插件和未知字段保留；公司鉴权、中转、自动授权审查和文件保护继续由企业层控制。没有新增界面或侧栏宽高行为。
